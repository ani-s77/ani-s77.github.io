Lightship, Senior Software Test Engineer

South San Francisco, CA · Jul 2026 – Nov 2026

Electric recreational vehicle (RV) company; tested the trailer's embedded control systems.

    1. Problem

      Sensor noise on the trailer could set off false alarms.

    2. What I did

      Generated synthetic noisy data to test the 250 ms smoothing filter, checking that sensors only reacted to real, sustained signals.

    3. Result

      Caught a bug that caused a false stop, making the system more reliable and the experience smoother for users.

  • Ran 15+ light-dimming tests in Python with simulated data to catch where actual brightness deviated from the firmware formula (concave, not linear), then escalated the hardware issue.
    1. Problem

      A 50% PWM duty cycle should mean 50% brightness, but the light output didn't follow it.

    2. What I did

      Validated the PWM data going in and out of the lights, running 15+ tests in Python with simulated data to tell circuit noise from the firmware formula.

    3. Result

      Showed brightness was concave, not linear (25% duty gave 91% brightness, 75% gave 50%), quantified the loss and raised it with engineering for the next hardware release.

    1. Problem

      Manual tests, automated tests, firmware updates and test suites all needed to be tracked and connected in one place.

    2. What I did

      Came up with the SQL database logic on AWS RDS: tracked test runs, firmware update runs and suite directories, and linked manual cases to automated ones using test IDs as primary and foreign keys.

    3. Result

      Any run can be filtered by user, scenario (release, nightly, ad hoc) and passed or failed status.

    1. Problem

      The team needed to see how each component was doing and act on failures without digging through raw results.

    2. What I did

    3. Result

  • Built and provisioned a hardware-in-the-loop (HIL) test server on my own, with a virtual machine for each of the trailer's ECUs.
    1. Problem

      Automated tests needed a hardware-in-the-loop (HIL) server to run against the trailer's control units.

    2. What I did

      Built and provisioned the HIL server on my own, with a virtual machine for each of the trailer's ECUs, and built the connection to the trailer's software.
